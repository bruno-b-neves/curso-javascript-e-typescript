# 🚀 Curso de JavaScript e TypeScript do Básico ao Avançado

Repositório destinado aos estudos, exercícios, projetos e anotações realizados durante o curso **JavaScript e TypeScript do Básico ao Avançado (JS e TS)**, ministrado por **Luiz Otávio Miranda**.

> O objetivo deste repositório é acompanhar toda a evolução no desenvolvimento Full Stack utilizando JavaScript e TypeScript, desde os fundamentos até aplicações completas com React, Node.js, APIs REST e Deploy.

---

# 📚 Sobre o Curso

O curso aborda JavaScript moderno (ES6+) e TypeScript, ensinando tanto o desenvolvimento **Front-end** quanto **Back-end**, utilizando as tecnologias mais empregadas no mercado.

Além da programação, também são apresentados conceitos de infraestrutura, segurança, testes automatizados, arquitetura de software e deploy em servidores Linux.

---

# 🎯 Objetivos

- Aprender JavaScript moderno (ES6+)
- Dominar TypeScript
- Desenvolver aplicações Front-end
- Desenvolver APIs e aplicações Back-end
- Construir aplicações Full Stack
- Trabalhar com bancos de dados SQL e NoSQL
- Criar aplicações React
- Fazer deploy em servidores Linux
- Aplicar boas práticas de desenvolvimento
